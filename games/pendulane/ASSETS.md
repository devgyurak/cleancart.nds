# Pendulane assets

[한국어](ASSETS-KO.md)

Every graphic, font, sound effect and piece of music in Pendulane is **generated by code in this repository at build time**. No
images, fonts, recordings or scores are taken from anywhere else, and no CC0 assets are used. All assets below are original work
under the same copyright and licence as the source: **Apache-2.0** (Copyright 2026 devgyurak, the cleancart.nds maintainer).

The generator is `tools/mkassets.py`; the code that draws, synthesises and lays out lives in `tools/cvtools/` (shared with the other
games). The same source always produces the same bytes.

The PNG files in `docs/images/` (if any) are README screenshots captured from the built ROM. They are documentation, not assets:
the build never reads them and they are not in the ROM.

| File (output) | Contents | Generator | Source / licence |
|---|---|---|---|
| `cv_font_tiles` | 5x7 pixel font (ASCII 0x20–0x5F), 4bpp | `cvtools/font.py` `GLYPHS` (glyphs drawn as strings) | original, Apache-2.0 |
| `cv_ui_tiles`, `cv_ui_pal` | frame and gauge tiles | `images.ui_tiles()` | original, Apache-2.0 |
| `cv_smp_*`, `cv_sound_bank`, `cv_sample_names` | the samples the engine links (`SAMPLES_USED` in `cvtools/audio.py`) | `cvtools/audio.py` `make_samples()` | original, Apache-2.0 |
| `cv_song_*`, `cv_song_names` | the song `pendulum` (steady dorian piece, no drums), composed by code; played on the title and in the credits | `cvtools/audio.py` `SONGS`, `compose()` | original, Apache-2.0 |
| `pd_snd_adpcm` | the sound bench's ADPCM block: header word (predictor 0, step index 50) and 32 samples of nibble 7, so the decoded output is non-zero from the first sample | `tools/mkassets.py` | original, Apache-2.0 |
| `probe.bin` (NitroFS) | 2 KB known-CRC file the cart check reads | `tools/mkassets.py` | original, Apache-2.0 |
| banner icon (`icon.bmp`) | 32x32 4bpp icon, a pendulum bob on a rod swinging in front of a gear | `tools/mkassets.py` `pendulane_icon()` | original, Apache-2.0 |
