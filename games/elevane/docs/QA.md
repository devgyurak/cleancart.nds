## Auto QA run

Hidden mode of the release ROM (`elevane.nds`): on the title screen press L and R, then X and Y,
and hold all four for 120 frames. The game plays the normal flow by itself (title → puzzle list → all 40 puzzles, played by the scripted player `game/script.c` → list → title → credits → title), writes the save once and ends with `RESULT PASS`. Log on the SD card
(`cleancart/elevane/qa-<date>-<time>.log`). Headless: `SDDIR=out/ev/x tools/melonds/mds.sh run
games/elevane/elevane.nds 20000 out/ev/x "300:L:140,300:R:140,300:X:140,300:Y:140"`. Verified 2026-11-11 in melonDS 1.1 (software renderer): `RESULT PASS` at frame 16 689 (after the review fixes), 40 of 40 puzzles delivered, chapters mask `0x1f`.
