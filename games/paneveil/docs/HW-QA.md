# Paneveil hardware QA (DS Lite + R4)

[한국어](HW-QA-KO.md)

Nothing in Paneveil has been measured on a console yet. The checklist (what the hardware has to
answer, the steps, how to record) is written with the judge changes, when the rehearsal ROM and the
items exist. The automatic route of skill `nds-hw-qa` already applies to the QA run: create the empty folder
`cleancart/paneveil/` on the card, and an empty file `cleancart/paneveil/autoqa` starts the QA run.
