# Ledgerine QA

[English](QA.md)

melonDS 1.1용 점검표입니다 (macOS 키는 저장소 루트 `AGENTS.md` 참고). 지금은 뼈대만 있습니다.

| 장면 | 확인할 것 | 상태 |
|---|---|---|
| 타이틀 | 위 화면에 탑 그림, "LEDGERINE", 한 줄 소개, X/Select 안내. 아래 화면에 라이선스·ARM7·저장 칩 줄. Start는 1번 방, X는 크레딧, Select는 테스트 메뉴 | 헤드리스 실행만 확인. melonDS 손 조작은 아직 |
| 테스트 메뉴 | 방 6개, 리허설, 크레딧. B는 뒤로 | 헤드리스 실행만 확인 |
| 방 (임시) | 방 이름, 탑, 하드웨어. A로 장부를 덮고 다음 방으로, 6번 방 뒤에는 크레딧 | 헤드리스 실행만 확인 |
| 크레딧 | 스크롤. X는 라이선스 뷰어(NitroFS 필요), B는 뒤로 | 아직 확인 전 |
