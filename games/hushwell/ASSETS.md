# Hushwell assets

[한국어](ASSETS-KO.md)

Every graphic, font, 3D model, sound effect, voice, piece of music and map in
Hushwell is **generated by code in this repository at build time**. No images,
fonts, recordings or scores are taken from anywhere else, and no CC0 assets are
used. All assets below are original work under the same copyright and licence as
the source: **Apache-2.0** (Copyright 2026 devgyurak, the cleancart.nds maintainer).

The generator is `tools/mkassets.py`; the code that draws, synthesises and lays out
lives in `tools/cvtools/`. The same source always produces the same bytes
(randomness is a fixed-seed xorshift; Python's `random` is not used). The "voices"
on the radio and the tapes are formant synthesis, not recordings of anyone.

The PNG files in `docs/images/` are README screenshots captured from the built ROM
in headless DeSmuME. They are documentation, not assets: the build never reads them
and they are not in the ROM.
