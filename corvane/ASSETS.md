# Corvane assets

[한국어](ASSETS-KO.md)

Every graphic, font, 3D model, sound effect, piece of music and stage layout in
Corvane is **generated by code in this repository at build time**. No images,
fonts, samples or scores are taken from anywhere else. All assets below are
therefore original work under the same copyright and licence as the source:
**Apache-2.0** (Copyright 2026 Corvane contributors). No CC0 assets are used either.

The generator is `tools/mkassets.py`; the code that draws and synthesises lives in
`tools/cvtools/`. The same source always produces the same bytes (randomness is a
fixed-seed xorshift; Python's `random` is not used).

The PNG/GIF files in `docs/images/` are README screenshots captured from the built
ROM in headless DeSmuME. They are documentation, not assets: the build never reads
them and they are not in the ROM.
