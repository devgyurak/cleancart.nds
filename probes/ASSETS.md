# Probes assets

[한국어](ASSETS-KO.md)

Every graphic, font, 3D model, sound effect, piece of music and stage layout in
the probes is **generated by code in this repository at build time** (the probes use the part of Corvane's asset set that Corvane's demos use, with copies of Corvane's generators). No images,
fonts, samples or scores are taken from anywhere else. All assets below are
therefore original work under the same copyright and licence as the source:
**Apache-2.0** (Copyright 2026 devgyurak, the cleancart.nds maintainer). No CC0 assets are used either.

The generator is `tools/mkassets.py` (trimmed); the code that draws and synthesises lives in
`tools/cvtools/`. The same source always produces the same bytes (randomness is a
fixed-seed xorshift; Python's `random` is not used).
